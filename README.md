## 🌐 About

Shreeza Tech is a modern software consulting company website built with **Laravel 12**, **Livewire 3**, **Volt**, **Flux UI**, and **Tailwind CSS v4**.

The website showcases our services, solutions, portfolio, careers, contact system, and company information with a modern, responsive UI.

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/shreeza-tech.git
```

Go into the project

```bash
cd shreeza-tech
```

Install PHP dependencies

```bash
composer install
```

Install Node packages

```bash
npm install
```

Create environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Run migrations

```bash
php artisan migrate
```

Start development server

```bash
php artisan serve
```

Run Vite

```bash
npm run dev
```
